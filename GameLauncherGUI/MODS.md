# Моды в PLAYSPACE

Раздел обнаруживает игры на текущем компьютере: установленные Steam- и Epic-игры плюс существующие локальные игры из библиотеки PLAYSPACE. Пути к играм не зашиты в приложение. Для Steam сохраняется каталог установки из манифеста, даже когда запуск выполняется через URI.

Встроенный каталог использует публичный API Thunderstore. Подключены Windows/BepInEx-адаптеры для R.E.P.O., Lethal Company, Valheim, Risk of Rain 2, ROUNDS, ULTRAKILL, Inscryption, Content Warning, PEAK и Dyson Sphere Program. Для MECCHA CHAMELEON и Palworld используются отдельные Unreal/UE4SS-адаптеры. Другие обнаруженные игры видны, но установка для них недоступна. Minecraft, Skyrim, GTA и другие экосистемы требуют отдельных адаптеров.

UE4SS-моды нужно запускать кнопкой «Играть» именно в PLAYSPACE. Лаунчер передаёт unreal-shimloader пути `--mod-dir`, `--pak-dir`, `--cfg-dir`, `--overlay-dir`; для Steam используется `steam.exe -applaunch` с отдельными аргументами. Файлы профиля расположены в `.playspace-mods/unreal`, файлы самого shimloader — рядом с Shipping-exe игры. MECCHA CHAMELEON поддерживает `mod/`, `Mods/<имя>/`, корневые `Scripts/`, community overlay и прямые PAK/UCAS/UTOC-патчи. Карты Steam Workshop этим каталогом не устанавливаются.

Перед установкой пользователь видит каталог назначения и точные версии всех пакетов. Зависимости разрешаются по указанным версиям. Установщик поддерживает обычные пакеты BepInEx; модпаки и исполняемые установщики исключены. Нестандартные архивы отклоняются с объяснением. Для обновления сначала требуется удалить старый пакет и его зависимые моды.

Файлы размещаются в папке подтверждённой игры. Отличающиеся существующие файлы не перезаписываются. Учёт файлов и журнал незавершённых операций хранятся в `.playspace-mods` внутри этой папки. Удаление учитывает общие зависимости, сохраняет чужие файлы и изменённые конфиги; изменённые бинарные файлы требуют ручной проверки. Сторонние менеджеры модов не синхронизируются с этим журналом.

Совместимость каждого мода с конкретной версией игры не гарантируется. Реальные API и архивы загрузчиков проверены, но игровые сессии с модами автоматически не тестируются.

Проверки без изменения установленных игр:

```powershell
dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release -- --ui
```

Дополнительная проверка реальных каталогов и архивов, требующая интернета:

```powershell
dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release -- --network-all
```

Проверки используют временные игровые папки. Сетевой режим только скачивает и разбирает пакеты, не устанавливая их в настоящие игры.
# Стратегии Paradox

Поддержаны Hearts of Iron IV, Europa Universalis IV, Stellaris, Crusader Kings III и Imperator: Rome. Игры и библиотеки Steam определяются на текущем ПК, папка пользовательских модов берётся из «Документов» текущего пользователя. Victoria 3 и Europa Universalis V пока не подключены: у них другой формат метаданных и списка загрузки.

В разделе модов доступны импорт ZIP одного мода с `descriptor.mod`, поиск среди установленных модов, включение/отключение и изменение порядка загрузки. Архив может содержать одну внешнюю папку. Установщики и нативные библиотеки из ZIP не поддерживаются. Учитываются объявленные зависимости по имени; совместимость модов, версии игры и DLC проверяет пользователь.

Кнопка Steam Workshop открывает мастерскую в Steam: подписку и скачивание выполняет клиент Steam. После загрузки нажмите «Обновить» в PLAYSPACE. Лаунчер регистрирует скачанный мод, сохраняя его исходные файлы в Workshop; снятие регистрации не удаляет файлы Steam.

Профиль и порядок сохраняются отдельно в `.playspace-mods` пользовательской папки игры. Перед прямым запуском из PLAYSPACE профиль применяется к `dlc_load.json`, сохраняя настройки DLC и неизвестные поля. Наборы Paradox Launcher не редактируются. Управление меняется только при закрытых игре и Paradox Launcher; кнопка возврата управления восстанавливает исходный список модов. Импортированные файлы удаляются только по журналу владения; изменённые сторонними программами файлы защищены от перезаписи.

Проверки стратегии используют временные файлы: импорт, зависимости, порядок, Workshop-регистрации, восстановление, отмена и защита путей. Они не подтверждают совместимость конкретного мода с запущенной игрой.

Описание формата HOI4 и прямого запуска: https://forum.paradoxplaza.com/forum/threads/new-launcher-for-hearts-of-iron-iv-on-the-13th-of-november.1273707/
