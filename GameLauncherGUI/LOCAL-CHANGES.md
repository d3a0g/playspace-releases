# Изменения версии 1.0.3

Изменения этого списка включены в выпуск 1.0.3. Исходники, инструкции по сборке и галерея интерфейса опубликованы под лицензией MIT; сторонние компоненты сохраняют свои лицензии.

## Интерфейс

- Единое поисковое поле: вертикальное выравнивание ввода, поиск-лупа, подсказка и очистка. Исправлены поиск библиотеки и рекомендаций.
- Новый стартовый экран: анимированный круг, текущая операция и загрузка библиотеки в фоне.
- 500 уникальных игр в рекомендациях. Основная подборка дополнена снимком публичной выдачи Steam по жанрам; данные встроены в EXE. Скрипт tools/Refresh-Recommendations.ps1 обновляет снимок локально, ничего не публикует.
- Описание игры преобразуется из HTML в компактные абзацы, списки и заголовки. Показываются разработчик, дата и жанры, когда Steam их предоставляет. Прокрутка и текст рисуются в общей палитре с AntiAliasGridFit.
- Escape закрывает дочерние разделы; на странице игры рекомендаций возвращает к каталогу. В поиске сначала очищает строку. Основное окно возвращает в библиотеку. Во время изменения файлов закрытие может ждать завершения операции/отката.
- Сглаживание текста в рисуемых элементах, совместимый рендеринг стандартных подписей и PerMonitorV2 DPI.
- Навигация коллекции получила мягкие цветные значки; оконные кнопки собраны в одну строку одинаковой высоты.

## Один переносимый EXE

Встроен постоянный адрес обновлений. update-source.json теперь необязателен: без него, при повреждённом JSON или пустом адресе используется встроенный канал. Файл по-прежнему можно использовать для переопределения. Пользовательские настройки, статистика и кэш остаются в LocalAppData/GameLauncherPRO. Секрет бота не включается в EXE.

## Моды

Добавлен Thunderstore-адаптер GTFO. Добавлено 14 ZIP-адаптеров: Stardew Valley (нужен SMAPI), RimWorld, XCOM 2, Factorio, архивные моды Cyberpunk 2077, The Witcher 3, Baldur's Gate 3, Divinity: Original Sin 2, Skyrim/Special Edition, Fallout 4/New Vegas/3 GOTY и Oblivion.

Существующие файлы не перезаписываются. Импорт и удаление используют журнал ModInstaller. Форматы, загрузчики, активация и зависимости различаются: интерфейс объясняет ограничения. Это не поддержка всех модов для всех 500 игр. Для Bethesda плагины активируются отдельно; SKSE/F4SE DLL не устанавливаются этим импортом. Для Larian принимаются PAK, для Cyberpunk — только архивные .archive, Factorio сохраняет ZIP штатного формата. Нативные зависимости не скачиваются автоматически.

## DLSS в разделе «Моды → DLSS / RTX»

Обнаруживаются уже имеющиеся nvngx_dlss.dll. Можно скачать DLSS Super Resolution из фиксированных официальных выпусков NVIDIA SDK (310.9.16 или 310.5.3), проверить Authenticode-подпись NVIDIA, заменить библиотеку с резервной копией и вернуть оригинал. Не меняются Frame Generation, Ray Reconstruction и файлы античита. Для известных сетевых игр/обнаруженных античитов замена отключена. Игра должна быть закрыта. Несовпадение хешей после внешнего изменения блокирует автоматическую перезапись и восстановление.

Это не гарантирует выбранную модель/пресет в каждой игре и не гарантирует рост FPS. GPU и драйвер должны поддерживать нужную функцию; установка нового SR DLL не добавляет DLSS игре, в которой его нет.

DLSS 5 Neural Rendering требует интеграции в рендер-пайплайн игры. Добавлен отдельный экспериментальный режим UniversalDLSS5 0.5.1: проверенная установка модуля, импорт подписанного NVIDIA NR runtime и запуск игры через контроллер. Это не гарантия совместимости всех игр. Подробности: UNIVERSAL-DLSS5.md.

Источники: https://github.com/NVIDIA/DLSS/releases ; https://developer.nvidia.com/blog/whats-new-for-game-developers-dlss-5-with-3d-guided-neural-rendering-nvidia-ace-updates-and-new-rtx-kit-capabilities/

## Telegram-поддержка

Контакт лаунчера — https://t.me/PlaySpaceSupport_bot . Исходный код обработчика находится в PlaySpace.SupportBot. Токен и идентификатор оператора — только в .secrets/support-bot.local.json, папка исключена через .gitignore и не входит в проект лаунчера.

Для запуска: powershell -NoProfile -ExecutionPolicy Bypass -File tools/Start-SupportBot.ps1 . Повторный запуск не создаёт второй poller. Сейчас обработчик настроен на локальный HTTP-прокси VPN http://127.0.0.1:10809: без работающего VPN Telegram API на этом ПК был недоступен. Для сервера с прямым доступом proxyUrl можно убрать. Бот работает, пока запущен отдельный обработчик; он не зависит от открытого окна лаунчера. Работа 24/7 потребует постоянно включённого ПК или отдельного сервера.

Оператор подключается одноразовой командой /claim с кодом из приватной конфигурации. После успешной привязки код очищается. Пользователь пишет боту версию, игру, проблему и скриншот; оператору пересылается обращение с Chat ID. Ответ: /reply CHAT_ID текст. Команда принимается только от привязанного оператора. Группы игнорируются, установлен лимит частоты сообщений. Токен не выводится в журналы и не должен попадать в README, EXE или репозиторий.

## Проверки

- dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release -- --ui
- dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release --no-build -- --network-dlss
- LauncherPlaySpace.exe --verify-package (проверка встроенных данных без открытия интерфейса)

Проверки игр, конфигов, ZIP и DLSS используют временные файлы. Реальные установленные игры не менялись. Отдельно проверена реальная загрузка официальной DLL NVIDIA и действительная цифровая подпись. Логика бота проверяется на подставных Telegram-ответах; реальный getMe, команды и описание проверены через собственный VPN-прокси владельца.
