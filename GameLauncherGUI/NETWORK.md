# Сеть / Cloudflare WARP

Включено в выпуск 1.0.4.

В боковой панели PlaySpace появился раздел «Сеть / WARP». Пользователь скачивает только лаунчер; установку официального компонента Cloudflare можно выполнить из этого раздела. Компонент не включён в ZIP и не перепаковывается.

## Первый запуск

1. Откройте «Сеть / WARP» и ознакомьтесь с условиями и политикой приватности Cloudflare по ссылкам в окне.
2. Подтвердите согласие и нажмите «Установить компонент». Лаунчер скачает актуальный официальный MSI для Windows x64, проверит формат и действительную подпись издателя Cloudflare.
3. Подтвердите запрос прав Windows. Используется штатный установщик с индикатором прогресса; автоматическая перезагрузка запрещена. Если Windows вернула код 3010, перезагрузите компьютер перед подключением.
4. Нажмите «Подключить». Для нового устройства создаётся личная регистрация WARP; существующая регистрация не удаляется. Выбирается полный режим `warp+doh`.
5. Дождитесь статуса клиента и нажмите «Проверить туннель». Подтверждение `warp=on` / `warp=plus` относится к запросу к Cloudflare, а не ко всем игровым серверам и сайтам.

Официальный пакет содержит службу, сетевые компоненты и интерфейс Cloudflare. Отдельного проверенного установщика только службы нет. Пользователю не требуется вручную искать установщик или открывать интерфейс Cloudflare для обычного подключения, но он остаётся установлен и доступен для диагностики.

## Поведение

- Открытие окна только проверяет статус. Оно не устанавливает компонент и не включает туннель автоматически.
- Статус обновляется каждые шесть секунд. Неизвестный вывод и ошибка CLI не выдаются за успешное подключение.
- Успешное завершение команды `connect` означает только принятие команды. Состояние клиента и проверка трафика отображаются отдельно.
- «Отключить» не требует повторного согласия и возвращает управление маршрутизацией официальному клиенту. PlaySpace не редактирует DNS или маршруты вручную.
- Закрытие окна и выход из лаунчера не отключают системную службу WARP. Состоянием можно управлять из PlaySpace или официального клиента.
- Управляемые профили организаций не перенастраиваются. Принудительной перерегистрации, удаления аккаунта или обхода политик нет.
- Подключение охватывает ПК, а не только запущенную игру. Конфликты с другим VPN возможны. Доступность конкретных ресурсов и улучшение пинга не гарантируются.
- Удаление WARP выполняется через «Параметры Windows → Приложения».

## Реализация и проверки

### Диагностика и отчёт для поддержки

Кнопка «Диагностика и отчёт» доступна даже без установленного WARP. Выберите Steam, Telegram, Rainbow Six Siege / Ubisoft или GitHub. Проверки запускаются только по кнопке: наличие сетевого подключения Windows, DNS выбранного адреса, TCP 443, ответ HTTPS, контрольный HTTPS-запрос Cloudflare, статус клиента WARP и отдельный запрос проверки туннеля.

На каждую сетевую проверку отводится до восьми секунд; её можно отменить. Переключение сервиса сбрасывает предыдущий отчёт. При отмене неполный отчёт не экспортируется. Открытие окна не вызывает установку, подключение WARP и другие изменения настроек.

HTTP 403/451/429 и ошибки сервера показываются отдельно от ошибок соединения. Наличие ответа не подтверждает работу всех функций сервиса; отсутствие ответа не доказывает блокировку провайдером. Для Rainbow Six Siege проверяется публичный сайт Ubisoft, а не игровые UDP-серверы, авторизация или матчмейкинг. Время TCP/HTTPS не выдаётся за игровой пинг.

В отчёт входят дата UTC, версия PlaySpace, версия и архитектура Windows, выбранный публичный адрес, результаты и рекомендации. Отчёт собирается из ограниченного набора полей, а не из системных журналов. IP-адреса, имена пользователей и компьютеров, личные пути, тексты системных исключений, регистрационные данные WARP, ключи и токены не собираются. Проверки выполняются без HTTP-прокси; отдельные программы могут иметь другой маршрут.

Кнопка «Просмотреть отчёт» открывает весь текст. Только после этого пользователь может сохранить TXT или скопировать его. «Открыть поддержку» открывает Telegram-бота без передачи отчёта; файл или текст нужно отправить самостоятельно. Автоматической отправки нет.

```powershell
dotnet run --project GameLauncherGUI.Tests -c Release -- --diagnostics-ui
```

Проверки используют имитацию сети и WARP: различают ошибки DNS и ответы сервера, проверяют отмену, список допустимых адресов, отсутствие личных данных в отчёте, кнопки и просмотр результатов.

`WarpNetwork.cs` обнаруживает CLI только по стандартному пути Program Files и проверяет подпись перед запуском. Загрузка разрешена по HTTPS только с `downloads.cloudflareclient.com`; переходы проверяются до отправки следующего запроса. Ограничение MSI — 180 МБ. При ошибках частичный файл удаляется. Перед повышением прав подпись проверяется повторно.

`msiexec /i ... /passive /norestart` запускается с запросом UAC. После начала установки процесс MSI не прерывается. Лаунчер не требует постоянного запуска от администратора. Согласие хранится отдельно от библиотеки в `network-consent.json`; регистрационные ключи WARP приложение не читает и не сохраняет.

Проверка туннеля обращается только к `https://www.cloudflare.com/cdn-cgi/trace` без HTTP-прокси. Из ответа используется поле `warp`; IP и остальные поля не показываются и не сохраняются. Эта проверка не подтверждает маршрут каждого приложения.

```powershell
dotnet run --project GameLauncherGUI.Tests -c Release -- --network-ui
```

Тесты используют подставной CLI, HTTP-ответы и установщик: проверяют согласие, регистрацию, управляемые профили, статусы, подписи, перенаправления, очистку файлов, коды MSI, кнопки, Escape и размеры интерфейса. Реальные игры, маршруты и службы не изменяются.

Официальный MSI версии 2026.8.2115.0 скачан и проверен при разработке; издатель — Cloudflare, Inc. Из него извлечён подписанный CLI и прочитана только справка `--help`, подтверждающая команды `registration`, `mode warp+doh`, `connect`, `disconnect`, `status`, `--accept-tos`, `--no-ansi`, `--no-paginate`. Установка с UAC и настоящее туннельное соединение на этом ПК не выполнялись.
