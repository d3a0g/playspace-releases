# Бот поддержки

Отдельный .NET 10 обработчик Telegram Bot API. Клиент лаунчера открывает ссылку поддержки; токен бота в приложение не встраивается.

1. Создайте своего бота через @BotFather.
2. Скопируйте `support-bot.example.json` в `.secrets/support-bot.local.json` в корне проекта. Запишите токен в `token` или задайте переменную `PLAYSPACE_BOT_TOKEN`. Не коммитьте конфигурацию.
3. При необходимости укажите собственный HTTP/HTTPS/SOCKS5 прокси в `proxyUrl`.
4. Запустите в консоли:

```powershell
dotnet run --project PlaySpace.SupportBot -c Release -- .secrets/support-bot.local.json
```

При первом запуске обработчик генерирует `pairingCode` и сохраняет его в приватный файл. Отправьте своему боту `/claim КОД` в личном чате. Код одноразовый; после подключения оператор сохраняется в `ownerChatId`.

## Меню пользователя

Постоянная клавиатура внизу чата: «Написать в поддержку», FAQ, скачивание актуального выпуска, основной репозиторий, статус обращения, инструкции и информация о проекте. FAQ содержит семь тем: установка, обнаружение игр, часы и достижения Steam, моды, DLSS, трей и подготовка обращения. Ссылки открываются отдельными кнопками под сообщением.

После первого описания проблемы создаётся номер обращения. Дополнения попадают в то же активное обращение; после его закрытия новый вопрос создаёт новый номер. Поддерживаются текст, скриншоты, документы, видео и аудио. Между сообщениями действует ограничение в две секунды; отклонённое сообщение нужно повторить.

## Панель оператора

После `/start` владелец видит отдельную клавиатуру: активные обращения, закрытые, статистика и помощь. Список разбит на страницы по восемь обращений. В карточке доступны «Ответить», «Запросить подробности» и «Закрыть». Цитата над карточкой ведёт к последнему сообщению пользователя.

Нажмите «Ответить» и ответьте на подсказку бота: в ней указаны номер и получатель. Ответ может содержать текст или вложение. Он копируется пользователю без ссылки на личный аккаунт оператора. Обычные сообщения администратора не пересылаются. Подсказка одноразовая; «Главное меню» и `/cancel` отменяют все незавершённые подсказки. Команда `/reply CHAT_ID текст` сохранена для совместимости, но для новых обращений не нужна.

Номера, имена, статусы, ссылки на сообщения и незавершённые подсказки хранятся в `support-tickets.local.json` рядом с приватной конфигурацией, обычно внутри `.secrets/`. Локального архива текста обращений нет; сообщения остаются в Telegram. Кнопки оператора проверяют ID владельца и личный чат. После перезапуска состояние сохраняется. Не публикуйте файлы состояния, токен и журналы.

## Аватарка

`Assets/support-avatar.png` — аватарка PlaySpace Support. Для установки через Telegram Bot API:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Set-SupportBotAvatar.ps1
```

Скрипт использует приватную конфигурацию, проверяет аккаунт бота и отправляет JPEG без обрезки изображения. Токен в вывод не попадает. API: https://core.telegram.org/bots/api#setmyprofilephoto.

## Проверки

```powershell
dotnet run --project GameLauncherGUI.Tests -c Release -- --support-bot
```

Проверяются меню, FAQ, ссылки, авторизация callback-кнопок, страницы очереди, ответ по подсказке, отмена, перезапуск, закрытие и сохранение приватности. Telegram в этих проверках имитируется; реальные сообщения не отправляются.

Для фонового запуска на Windows предусмотрен `tools/Start-SupportBot.ps1`. Компьютер или сервер с обработчиком и доступом к Telegram должен оставаться включённым. Публикация исходников сама по себе не разворачивает сервер и не переносит действующего бота на чужой ПК.
