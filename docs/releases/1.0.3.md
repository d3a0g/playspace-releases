## Интерфейс и библиотека
- Исправлены поиск игр и выравнивание оконных кнопок. Обновлены значки коллекций и сглаживание текста.
- При запуске показываются анимированный индикатор и текущее действие; библиотека загружается в фоне.
- Клавиша Escape возвращает из разделов, а в поиске сначала очищает запрос.
- Адрес обновлений встроен в EXE: update-source.json больше не нужен для переноса приложения.

## Рекомендации и Steam
- Каталог расширен до 500 игр с категориями и закреплением понравившихся проектов.
- На странице игры доступны скриншоты, полное описание Steam и переход в магазин.
- Для подключённого Steam-профиля показываются общее наигранное время и доступные достижения.

## Моды и поддержка
- Добавлены GTFO в каталог Thunderstore и адаптеры импорта ZIP для ряда игр. Поддержка зависит от игры и формата мода.
- Добавлен экспериментальный модуль UniversalDLSS5 0.5.1: проверка загрузок, отдельный импорт NVIDIA runtime и ограничения для сетевых игр. Совместимость со всеми играми не гарантируется; runtime не включён в поставку.
- Поддержка открывается через Telegram-бота @PlaySpaceSupport_bot.
