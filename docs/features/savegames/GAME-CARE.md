# Управление игрой: копии, запуск и заметки

Включено в выпуск 1.0.4.

Откройте контекстное меню установленной игры → «Управление игрой · копии и запуск…».

## Добавлено 12 функций

1. Единое окно управления выбранной игрой с разделами «Сохранения и копии» и «Запуск и заметки».
2. Выбор отдельной папки сохранений или конфигурации. Универсального поиска сохранений нет: папку подтверждает пользователь.
3. Ручное создание точек восстановления с датой, количеством файлов и размером.
4. Проверка целостности всех файлов по SHA-256 и длине.
5. Предпросмотр восстановления: какие файлы будут созданы, заменены или останутся без изменений.
6. Страховочная копия текущего состояния перед восстановлением и попытка отката при ошибке записи.
7. Необязательное создание копии перед запуском из PlaySpace — до применения профиля производительности.
8. Проверка готовности: путь запуска, корректность Steam ID, работающий процесс, папка автокопирования, поддержка профиля и свободное место.
9. Исправление пути к EXE после перемещения игры. Это не перемещение и не переустановка самой игры; Steam ID сохраняется.
10. Личные заметки об игре, до 8000 символов, сохраняются локально в библиотеке.
11. Редактор параметров запуска. Строка разбирается по правилам Windows; параметры передаются отдельными аргументами. Поддерживаются локальные EXE и запуск через Steam.exe.
12. Режим игры в «Настройки → Приложение»: сворачивание после запуска и возврат по завершении отслеживаемых игр.

## Работа с копиями

Выберите папку игры и нажмите «Создать копию». Выбранная папка может содержать сохранения, настройки или их общий игровой каталог. Не выбирайте всю папку пользователя, Windows, корень диска или каталог лаунчера. Исполняемые файлы и скрипты Windows в выбранной папке не допускаются. Папки-ссылки, junction и UNC-пути не поддерживаются.

Одна точка содержит до 2 ГБ и 10 000 файлов; просмотр дерева ограничен 20 000 объектами. Для игры сохраняется до 50 точек. При достижении лимита новые копии блокируются с объяснением: старые не удаляются автоматически. Их можно перенести вручную через «Открыть папку резервных копий». Пустые каталоги отдельно не сохраняются.

Копии находятся в `%LOCALAPPDATA%\GameLauncherPRO\game-backups\<идентификатор игры>`. Идентификатор сохраняется в библиотеке и не зависит от имени игры или исправленного пути EXE. Копия содержит список файлов, размеры, SHA-256 и данные файлов. Это локальный архив: шифрования, загрузки в облако и автоматической отправки нет.

Перед операциями закройте игру и дождитесь синхронизации Steam Cloud / другого облачного клиента. Лаунчер проверяет известный основной процесс, но не может гарантировать обнаружение всех вспомогательных процессов и фоновой синхронизации. При необходимости задайте процесс учёта времени через существующий пункт контекстного меню.

Восстановление сначала проверяет все файлы выбранной копии, показывает папку назначения и план, затем требует явного подтверждения. Перед заменами создаётся новая точка «Перед восстановлением». Файлы, которых нет в выбранной копии, не удаляются. Поэтому это восстановление содержимого сохранённых файлов, а не полное зеркалирование каталога.

Каждый файл заменяется через временный файл. При обнаруженной ошибке или отмене делается попытка вернуть уже заменённые файлы из страховочной копии. Файл, изменённый посторонней программой после замены, не перезаписывается при откате; пользователь получает предупреждение. Аварийное выключение ПК не даёт гарантии автоматического завершения отката: страховочная точка остаётся для ручного восстановления. Новые пустые каталоги могут остаться после прерванной операции.

Если автокопия включена, её ошибка останавливает запуск игры — лаунчер не пропускает выбранную пользователем защиту молча. Автокопирование действует только при запуске через PlaySpace, не перед всеми установками модов и не при запуске из другого клиента.

## Запуск и режим игры

Исправление EXE сохраняет выбранный новый путь; старые файлы игры не удаляются. Изменить путь работающей игры нельзя. Для Steam исправление локального пути помогает проверкам и отслеживанию, но запуск по-прежнему использует тот же Steam App ID.

Редактор параметров не гарантирует, что игра поддерживает указанную команду. Для Steam с пользовательскими параметрами требуется установленный Steam.exe. PlaySpace не меняет глобальные параметры запуска в настройках Steam.

Режим игры выключен по умолчанию. При включении лаунчер остаётся работающим в трее. Возврат учитывает только игры, запуск которых был передан через PlaySpace; при нескольких таких играх окно возвращается после завершения последней. Если процесс не был обнаружен в течение пяти минут ожидания запуска, ожидание прекращается и окно может вернуться. Ошибки определения процесса возможны: уточните основной EXE игры.

Предварительная проверка не оценивает все системные требования, библиотеки, совместимость модов, FPS или доступность игровых серверов. Нехватка менее 512 МБ показывается как замечание, а не как вычисленная потребность конкретной игры.

## Проверки

```powershell
dotnet run --project GameLauncherGUI.Tests -c Release -- --game-care-ui
```

Используются только временные каталоги и фиктивные EXE, которые не запускаются. Проверяются копии, хеши, страховочная точка, откат при имитации ошибки записи, отмена, блокировка операций, повреждённые данные, чужой идентификатор, обход путей, параметры запуска, готовность игры, настройки, режим игры и интерфейс. Реальные сохранения и установленные игры в этих проверках не изменяются.
