# Оборудование и внешние тесты

Снимок проверен 7 ноября 2026 года. Данные встроены в приложение и доступны без сети; браузер открывается только по кнопке источника.

- 337 отдельных опубликованных замеров, 9 настольных GPU, 11 игр и 39 сочетаний CPU/GPU. Не каждое сочетание протестировано во всех играх.
- Steam Hardware Survey за октябрь 2026: 32 популярных GPU, основные объёмы RAM и число ядер. Опрос включает разные платформы и ноутбуки.
- Пять ссылок на YouTube для сопоставления оборудования и методики. Числа из видеокадров не извлекались; эти ссылки не увеличивают число замеров FPS.

Steam публикует анонимные распределения отдельных компонентов, а не список пользователей с полными конфигурациями. CPU/GPU взяты из реальных строк тестовых стендов первичных обзоров. RAM не выводится из популярности памяти в Steam: если она неизвестна, это явно отмечено. Доля Steam в таблице стендов относится только к GPU.

## Воспроизводимость

`GameLauncherGUI.Tests/Features/Performance/HardwareEvidenceImport.cs` импортирует отдельные строки `gamebench_*`, а не округлённые сводные значения. На игру/GPU выбираются до трёх групп пресет/разрешение и до двух строк в группе. Это ограниченная выборка, а не полный архив измерений. Дубликаты по издателю и идентификатору наблюдения исключаются.

Сохранённые HTML и их SHA256 находятся локально в `artifacts/hardware-catalog`; хеш снимка Steam также включён в `Assets/steam-hardware.json`. Для повторного импорта используется тестовый флаг `--import-hardware-evidence` при наличии этих исходных HTML. Флаг `--hardware --ui` проверяет каталог, фильтры и ClearType нативного поля ввода.

## Отображение

Вкладка «Тесты» фильтруется по выбранной игре и GPU. Кнопка «Показать всё» позволяет просматривать другие системы. «Источники и методика» содержит отдельные разделы стендов, FPS, Steam, обзоров и методики. Таблица показывает исходные измерения, а не прогноз или замер клиентского ПК. В компактном окне подробности доступны через всплывающие подсказки и отдельное окно источников.

Кнопки разделов настроек получили заливку, контур и маркер активного раздела. Для собственного рисования и подписей используется ClearType; нативные поля ввода получают шрифт с ClearType quality. Системные параметры сглаживания Windows не изменяются.
