# Справочник внешних замеров

Проверено 7 ноября 2026 года. В `Assets/benchmarks-expanded.json` включены 337 опубликованных замеров для 9 GPU, 11 игр и 39 сочетаний CPU/GPU. Статистика Steam содержит 32 популярных GPU за октябрь 2026. Это отдельные компоненты, а не связанные конфигурации игроков. Подробности: [HARDWARE-CATALOG.md](HARDWARE-CATALOG.md).

Источники чисел:

- [Notebookcheck RTX 3060](https://www.notebookcheck.net/NVIDIA-GeForce-RTX-3060-Desktop-GPU-Benchmarks-and-Specs.579000.0.html): строки Cyberpunk 2077 **1.6**, CPU Ryzen 9 5900X.
- [Notebookcheck RTX 4060](https://www.notebookcheck.net/NVIDIA-GeForce-RTX-4060-GPU-Benchmarks-and-Specs.741899.0.html): строки Cyberpunk 2077 **1.6**, CPU Ryzen 9 7950X.
- [Notebookcheck RX 5600 XT](https://www.notebookcheck.net/AMD-Radeon-RX-5600-XT-Desktop-GPU-Benchmarks-and-Specs.459227.0.html): отдельные строки Cyberpunk 2077 **1.6** с 5900X и 7950X, а не округлённое среднее из общей таблицы GPU.
- [GamesRadar RTX 4060](https://www.gamesradar.com/nvidia-geforce-rtx-4060-review/): таблица **DLSS 3 off**, Ultra/highest, три разрешения для трёх игр. CPU и точный патч в использованной таблице не указаны, это явно отмечено. RT off подтверждён текстом для Cyberpunk; для других игр RT не подписан и записан как not specified.

Видео для сопоставления методик: [Hardware Unboxed](https://www.youtube.com/watch?v=lIftP0Ut2lU), [Gamers Nexus](https://www.youtube.com/watch?v=WS0sfOb_sVM). Числа с кадров этих роликов автоматически не извлекались и не представлены как отдельные измерения. Видео и статья одной лаборатории не должны удваивать выборку.

## Как считается ориентир

Группы разделяются по игре, GPU, патчу, пресету, разрешению, RT, масштабированию, генерации кадров и идентификатору методики. Дубликаты публикации/наблюдения учитываются один раз. Для нескольких замеров показывается арифметическое среднее опубликованных средних FPS, минимальное/максимальное значение и размер выборки. Разные CPU перечислены; для таких групп отображается предупреждение. Это не объединение исходных времён кадров и не оценка статистической погрешности.

Исторические тесты Cyberpunk 1.6 не выдаются за производительность актуального патча. Значения не пересчитываются коэффициентами для другого CPU, мобильной видеокарты, Ti/XT-варианта или произвольного пресета. Если GPU, игра и разрешение не найдены, показывается отсутствие данных. Неизвестные условия остаются неизвестными.

Внешние результаты **не меняют настройки автоматически**. Они показаны отдельно от личного замера и не гарантируют FPS на клиентском ПК. Подбор цели продолжает опираться на введённый пользователем замер и частоту экрана. Результат после изменений нужно измерять в той же сцене; одного среднего FPS недостаточно для оценки плавности.
