# Библиотека и настройки PLAYSPACE

Кнопка «▦ / ☰» переключает список и постеры Steam. Изображения загружаются асинхронно и кэшируются; при недоступной обложке остаются название и иконка. Баннер выбранной игры отображается без размытия. Контекстное меню позволяет изменить иконку, открыть папку игры и локальные скриншоты Steam.

## Статистика Steam

В «Настройки → Профиль Steam» указываются SteamID64 и личный Web API key. «Сохранить и обновить все игры» загружает достижения и общее время всей доступной Steam-библиотеки. При запоминании ключ хранится в Windows Credential Manager, а не games.json. Без запоминания ключ остаётся в памяти до выхода. Отключение профиля удаляет сохранённые данные и связанный прогресс из карточек.

Общее время получается через GetOwnedGames, включая сыгранные бесплатные игры. Значение playtime_forever переводится из минут в часы. Оно хранится отдельно от локального счётчика, с идентификатором профиля и временем получения. Локальные сессии не прибавляются к часам Steam. Источник указан в карточке; сортировка по времени использует общий результат Steam. При смене профиля старые часы очищаются.

Обновление выполняется при запуске с сохранённым профилем, вручную из настроек, каждые 10 минут и после завершения обнаруженной игровой сессии (не чаще одного запроса в 30 секунд). Steam может обновлять своё время с задержкой. Отсутствие данных, закрытый профиль и сетевая ошибка не обнуляют последние загруженные часы. Если Steam ещё не предоставил время, карточка показывает «время не загружено». Для доступа должны быть открыты игровые сведения профиля и наигранное время.

Для игр вне Steam остаётся локальный счётчик: он работает, пока запущен PLAYSPACE, включая трей. Проверка процессов выполняется каждые 5 секунд. Основной EXE можно выбрать вручную в контекстном меню. Локальный счётчик сохраняется отдельно и для Steam-игр, но не заменяет успешно загруженное общее время.

Документация: https://partner.steamgames.com/doc/webapi/IPlayerService и https://partner.steamgames.com/doc/webapi/ISteamUserStats

## Крестик и трей

По умолчанию крестик предлагает «Свернуть в трей» или «Выйти полностью». Флажок «Запомнить выбор» сохраняет действие. Закрытие самого диалога отменяет закрытие лаунчера. В «Настройки → Приложение» можно выбрать: каждый раз спрашивать, всегда сворачивать в трей или всегда выходить полностью. Настройка хранится в preferences.json текущего хранилища лаунчера.

Двойной щелчок по значку трея возвращает окно. Команда «Выход» в меню трея всегда завершает приложение. Завершение Windows не блокируется диалогом.

## Рекомендации

Каталог содержит 288 уникальных игр с категориями, поиском и отдельным списком закреплённых игр. Это редакционная подборка, а не персональный рейтинг Steam. Карточки используют тот же компонент, что библиотека; постеры загружаются четырьмя очередями. Закреплённые рекомендации хранятся отдельно от установленных игр.

Один щелчок открывает страницу игры: до 12 скриншотов со стрелками, кнопки официального Steam Store и закрепления, затем полное прокручиваемое описание магазина. Описание преобразуется из HTML в текст без выполнения внешнего кода. Escape возвращает к подборке; стрелки клавиатуры переключают скриншоты, если фокус не в описании. Описания кэшируются. Сортировка библиотеки оформлена округлой кнопкой и меню: порядок добавления, название, последние запуски и время игры; закреплённые сохраняют приоритет.

## Проверки

`dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release -- --ui`

Проверяются импорт общих часов, настоящий ноль Steam, сохранение кэша при закрытой статистике, отделение локального времени, сортировка, общий запрос библиотеки, персонализация, категории, закрепление, страница игры, карусель, настройки закрытия, отмена, запоминание и полный выход. Используются временные файлы и тестовые HTTP-ответы; реальный аккаунт Steam не подключается.
