# Библиотека, персональная подборка и доступность

## Где найти

- **Моё пространство → Найти и объединить дубликаты**; также контекстное меню игры.
- **Контекстное меню игры → Перенести игру на другой диск**; также «Моё пространство» для выбранной игры.
- **Настройки → Главная страница** — начальный раздел, сортировка, баннер, список или постеры, персональные рекомендации.
- **Рекомендации → Для вас** — подборка по жанрам закреплённых игр и времени игры. Установленные Steam-игры исключаются. Причина показана в карточке. При недостатке данных это прямо указано. Обработка локальная, прогноз производительности не выполняется. Отключение применяется при следующем открытии рекомендаций.
- **Настройки → Оформление** — размер текста, уменьшение анимаций, яркий текст и памятка клавиатуры.
- **Моды → Наборы модов** — сохранение и переключение существующих наборов. Перед активацией показываются включаемые, отключаемые моды и смены версий.

## Дубликаты

Совпадение названия не является основанием для объединения. Учитываются Steam AppID и нормализованный путь EXE. Разные Steam AppID не смешиваются даже через третью запись с общим путём; разные аргументы запуска без общего AppID сохраняются отдельно.

Пользователь выбирает запись, чей путь и параметры запуска сохранятся. Закрепления и коллекции объединяются; время берётся по максимуму, а не суммируется. Steam-статистика разных аккаунтов не смешивается. До изменения создаётся копия в `library-backups` каталога данных лаунчера. Удаляются только записи, файлы игр остаются. Старые записи истории сохраняются в журнале, но их идентификаторы не переписываются.

## Перенос

1. Закройте игру и игровые клиенты. Выберите родительскую папку назначения: конечная папка игры должна быть новой.
2. Проверьте исходную папку, назначение и объём в плане. Лаунчер сверяет SHA-256 исходных и скопированных файлов, не перезаписывая существующую папку.
3. После проверки исходная папка переименовывается в страховочную, а по старому пути создаётся NTFS junction. В библиотеке используются реальные новые пути. Встроенные профили модов перепривязываются к новому корню.
4. Убедитесь, что игра запускается. Закройте игру и клиент, затем отдельно нажмите **Освободить место**. До этого исходный диск не освобождается.
5. До удаления страховочной копии доступен **Возврат исходной папки**. Новая копия при возврате остаётся на целевом диске; изменения, сделанные в ней после переноса, автоматически назад не сливаются.

Нужен локальный исходный диск NTFS; сетевые пути, вложенные назначения, ссылки внутри игры и общие системные папки не поддерживаются. Старую junction нельзя удалять, целевой диск должен быть подключён. Это перенос средствами файловой системы, а не официальная операция магазина; совместимость каждого магазина и античита на реальных играх не гарантируется.

Журналы находятся в `game-transfers`. При отмене копирования исходная игра остаётся на месте, частичная целевая папка сохраняется для проверки. Возврат архивирует журнал и не удаляет эту папку. Отмена ожидает завершения копирования/хеширования текущего файла. Завершающая проверенная очистка не прерывается кнопкой отмены, чтобы не оставлять половину удалённой копии; её журнал позволяет повторить очистку после ошибки ввода-вывода.

Удаление страховочной копии блокируется, если скопированные файлы изменены или повреждены. Новые дополнительные файлы, например логи, допустимы. Если игра изменила исходные конфигурации или моды, проверьте папки вручную — лаунчер не удаляет страховочные данные при несовпадении хешей. Сначала завершите перенос, затем устанавливайте новые моды.

Основа сохранения старого пути — [junction Windows](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/mklink).

## Прозрачность модов

Для каталога показаны авторы, версии, зависимости, адреса загрузки и размеры архивов, если их сообщил источник. Неизвестный размер не считается нулевым. Для локального ZIP показаны источник, размер после распаковки, папка модов и список содержимого; автор и зависимости не выдаются за проверенные.

Точные конечные пути и конфликты проверяются существующим установщиком после чтения архива. Предпросмотр не означает проверки безопасности стороннего кода. «Без управляемых модов» отключает только файлы PLAYSPACE, а не все сторонние моды игры.

## Клавиатура и вспомогательные средства

Tab переключает элементы, Enter/Пробел активирует стандартные кнопки. В списке игр работают стрелки, Home/End, PageUp/PageDown, Ctrl+D для закрепления, Alt+Enter для профиля и Shift+F10 для контекстного меню; Escape возвращает из разделов. Карточки открыты через accessibility API как элементы списка, описание — как текст. Проверены программные роли и выбор; ручная проверка с Narrator и всеми масштабами Windows остаётся отдельной задачей.
