# Ограничение скорости загрузок

Открыть **Моё пространство → Центр загрузок** или **Настройки → Загрузки**. Указать число, выбрать единицу и нажать **Применить**. Значение **0** снимает лимит. Настройка сохраняется между запусками и применяется также к текущей загрузке.

| Единица | Значение |
| --- | --- |
| Мбит/с | Миллионы бит в секунду |
| Мбайт/с | Миллионы байт в секунду |
| 8 Мбит/с | 1 Мбайт/с |

Переключение единиц в редакторе сохраняет физический лимит, а не просто меняет подпись числа. В списке и сведениях о текущей загрузке показывается измеренная скорость в выбранной единице. Для завершённых загрузок скорость равна нулю. Первое измерение требует небольшого интервала накопления данных.

Лимит относится к общей очереди загрузок модов Thunderstore, DLSS/OptiScaler и компонента WARP. Steam, Epic, браузерные загрузки обновления приложения, обложки и другие отдельные HTTP-запросы регулируются независимо. Это не системное ограничение сетевого адаптера. Лимит регулирует полезные данные чтения ответа; буферы HTTP/ОС, TLS и служебный трафик не являются точным счётчиком сетевых пакетов.

Внутри очередь выполняет одну сетевую задачу за раз; скорость ограничивается короткими отменяемыми ожиданиями с повторным чтением настройки. Отключение лимита действует без перезапуска загрузки. Проверенный дисковый кеш не замедляется сетевым ограничителем. Повторная загрузка по-прежнему только наполняет кеш, установка запускается из исходного раздела.

Расписания и ночные задания не добавлены.
