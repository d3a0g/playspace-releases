# Обновления игр и помощь при запуске

## Центр обновлений игр

Открывается через **Моё пространство → Обновления игр** или контекстное меню игры. Показывает все игры библиотеки, известный клиент и состояние установки.

Для Steam читаются локальные `appmanifest_*.acf` в библиотеках клиента. Доступны установленная/целевая сборки и сведения о подготовленной или частично завершённой загрузке. При нескольких манифестах приоритет имеет совпадающая папка установки. Если подготовленная загрузка не обнаружена, отображается **Проверить в клиенте**, а не обещание актуальной версии. Сведения могут быть устаревшими, пока Steam не обновил свои манифесты.

Для Epic Games, Ubisoft Connect и Riot Client доступны переходы в соответствующий клиент, если он распознан. Пользовательские папки Epic сопоставляются с локальными манифестами установки. Неизвестная локальная игра не получает выдуманный статус обновления. Кнопка открытия для неё открывает папку.

Лаунчер не переписывает манифесты, не меняет ветки и не устанавливает обновления магазина самостоятельно. Последнюю доступную версию, очередь и загрузку проверяет сам магазин: [справка Steam](https://help.steampowered.com/en/faqs/view/71AB-698D-57EB-178C), [справка Epic Games](https://www.epicgames.com/help/c-32735058/c-31292734/a12539006). Web API `UpToDateCheck` не используется как универсальная проверка build ID всех игр и веток.

## Помощник запуска

После явного запуска из лаунчера отслеживается выбранный игровой EXE. Автоматическое предложение появляется при ошибке передачи запуска, отсутствии наблюдаемого процесса в течение трёх минут или быстром исчезновении ранее замеченного процесса. Короткому исчезновению даётся 15 секунд на передачу запуска другому процессу. После 45 секунд наблюдаемой работы обычное завершение уже не вызывает предложение. Игры, запущенные вне лаунчера, этим помощником не проверяются.

Это эвристика, не определение аварийного завершения: обычный быстрый выход, авторизация клиента, выбранный EXE загрузчика и недостаток доступа к процессам могут дать похожую картину. Причина и код завершения этим способом не устанавливаются.

В помощнике доступны клиент/обновления, настройки графики и откат, моды и наборы, файлы/копии игры и выбор EXE для отслеживания. Повтор **без подготовки** пропускает автоматическое применение графического профиля и автоматические аргументы модов. Сохранённые аргументы запуска сохраняются, поскольку они могут быть обязательны для клиента. Уже изменённые конфиги и установленные моды автоматически не откатываются.

Показ отключается в **Настройки → Запуск и трей** или в самом помощнике. Ручной доступ остаётся через меню игры и «Моё пространство». Когда главное окно скрыто, предложение не разворачивает его принудительно; системное уведомление зависит от общей настройки уведомлений. Нажатие открывает помощник. Уведомления об обновлении лаунчера открывают своё окно.

Хранятся последние 30 записей в `launch-issues.json` каталога данных. Они локальны, не отправляются автоматически и не содержат паролей/API-ключей или аргументов запуска. Запуск сторонних диагностических программ и изменение файлов игры выполняются только по явным действиям пользователя в соответствующих разделах.
