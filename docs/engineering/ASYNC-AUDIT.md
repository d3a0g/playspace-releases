## Что оставлено намеренно

- Обычных именованных `async void`-методов в проверенных папках больше нет. Асинхронные лямбды обработчиков событий остаются: они ожидают рабочие `Task` либо запускают наблюдаемое обновление представления.
- `UiTaskScope.Start` возвращает `void`, но это синхронная граница запуска: её внутренний `RunCore` ожидает задачу, перехватывает ошибки, сообщает их владельцу и освобождает состояние. `RunAsync` предназначен для ожидаемого вызова на границе UI и также обрабатывает ошибку; внутренние сервисные методы продолжают возвращать обычные faultable Tasks.
- Внутренние `_ = RunCore(...)` и `_ = CompleteAsync(...)` оставлены только в двух классах, реализующих наблюдение и владение задачами. Это не необработанные задачи бизнес-логики.
- `Task.Run` оставлен для синхронного сканирования процессов/файлов, GDI+, WMI, разбора большого JSON и файловых транзакций. Асинхронный метод не означает автоматический перенос такой работы в фон.
- `Task.Result` размера папки читается только после `IsCompletedSuccessfully`. `queue.Wait(0)` — неблокирующая проверка доступности очереди для очистки кеша. Блокирующих ожиданий незавершённых задач на UI-пути при проверке не найдено.
- Нельзя прерывать применение файлов посередине. Существующие запреты закрытия при установке, переключении профиля, восстановлении и очистке сохранены; отмена применяется до транзакции, после её начала выполняется завершение или откат.
- Очередь повторной загрузки принадлежит приложению, а не окну списка загрузок: закрытие списка не отменяет уже заказанную загрузку. Её ошибки отражаются в состоянии очереди; закрытый список не обновляется. Полный выход из лаунчера отменяет активные и ожидающие загрузки через `CancelAll`.
- Бот обрабатывает обновления последовательно с `await`; его состояние не стало многопоточным. Работающий экземпляр бота не перезапускался.

## Проверки

`dotnet run --project GameLauncherGUI.Tests/GameLauncherGUI.Tests.csproj -c Release -- --async-audit` — 21 проверка ошибок синхронной фабрики и асинхронного продолжения, поздней ошибки после закрытия, повторного запуска, отмены, принадлежности UI-потоку, отмены HTTP Steam и ожидания семафора, ошибки загрузки рекомендаций и перехода очереди в Failed при неожиданной ошибке.

Общий запуск `--ui` дополнительно проверяет моды, откат файлов, сохранения, настройки, Steam, DLSS, сеть, бота и интерфейс на временных данных. Реальные игры, сетевые настройки, обращения пользователей и установка компонентов в этих тестах не меняются.

## Границы результата

Это аудит текущих исходников и регрессионные тесты, не математическое доказательство отсутствия всех гонок и не антивирусная проверка. Синхронные операции ОС нельзя гарантированно остановить посередине: они могут кратковременно завершаться после закрытия, но их результат не применяется к закрытому окну. Не проверялись реальные сбои питания, принудительное завершение процесса посередине записи, все сторонние драйверы или задержки всех внешних сервисов.
