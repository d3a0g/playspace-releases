# Новый интерфейс и настройка графики

Изменения подготовлены для выпуска 1.0.5.

В выпуск включён только новый интерфейс. Архивные копии старого интерфейса и инструменты его восстановления не включаются в публикацию.

## Навигация

- Библиотека и инструменты разделены, обычные пункты боковой панели стали спокойнее; выделяется текущий раздел.
- «Добавить» содержит поиск установленных игр и ручной выбор EXE.
- «Ещё» содержит удаление выбранных записей и очистку библиотеки. Эти действия не удаляют установленные игры.
- Настройки разделены на Steam, запуск и трей, оформление, уведомления, обновления, данные и помощь, ярлыки и историю изменений.
- В производительности отдельные вкладки «Экран», «Графика», «Тесты», «Изменения». На последней доступно сравнение текущих и выбранных значений без записи файлов.

## Реальное применение настроек

**Unreal Engine:** разрешение, экранный режим, VSync, лимит FPS/без лимита, масштаб рендера и десять отдельных Scalability Groups. Текущие значения читаются из существующего `GameUserSettings.ini`, выбранные значения сохраняются в профиль. Значения качества ограничены 0–3. Поддерживаются адаптеры каталога и распознаваемые сборки Unreal; конкретная игра может переопределять общие параметры движка.

**Cyberpunk 2077:** отдельный адаптер `UserSettings.json`. Читаются существующие параметры графики и экрана с описанными в файле вариантами или диапазонами. Разрешены только эти значения; связанные `value` и `index` сохраняются согласованно. Настройки управления не редактируются. Параметры без безопасно определяемого набора значений не предлагаются. Профили «Скорость / Баланс / Качество» меняют распознаваемые уровни качества; скорость и баланс отключают существующие булевы RT-параметры. Они не включают DLSS FG на неподдерживаемом GPU.

**Unity и CS2:** остаются поддерживаемые параметры запуска, разрешение/режим экрана; для CS2 — `fps_max`, включая 0. Отдельное редактирование всех графических настроек этих игр не заявляется.

«Сохранить» сохраняет профиль. «Применить и играть» передаёт запрос штатному запуску игры; конфиг применяется перед запуском при включённом профиле. Игра должна быть закрыта. Оригинальный файл сохраняется в `.playspace-backup`, повторная настройка не перезаписывает эту копию; откат восстанавливает её байт-в-байт. Файлы и папки-ссылки не поддерживаются. Неподдерживаемые возможности отключены, а не имитируются.

Это не управление драйверными профилями NVIDIA/AMD и не универсальная замена всех игровых меню. Одинаковый внешний вид не создаёт API для неподдерживаемых игр.

## Исходные схемы

- [Epic: Scalability Reference](https://dev.epicgames.com/documentation/en-us/unreal-engine/scalability-reference-for-unreal-engine) — группы качества Unreal.
- [Пример UserSettings.json и описание пользовательских настроек Cyberpunk](https://github.com/steliosc/Cyberpunk-2077-Custom-Controls-Guide/blob/main/UserSettings.json) — сверка структуры. Публичный пользовательский файл не включён в исходники лаунчера; тесты используют искусственные данные. Реальная схема проверяется при чтении файла на клиентском ПК.

Внешние тесты и ограничения оценки FPS описаны в [BENCHMARKS.md](../features/performance/BENCHMARKS.md).
