# Локальная тестовая версия 1.0.5-preview

Изменения пока не публикуются в GitHub и не меняют пользовательский канал обновлений.

## Что добавлено

1. Установщик Inno Setup для Windows x64, установка текущему пользователю в `%LOCALAPPDATA%\Programs\LauncherPlaySpace`. При повторной установке используются прежние AppId/папка, более новая версия не заменяется старой. Лаунчер нужно закрыть, включая трей. Создаются обычные локальные ярлыки и ярлык безопасного режима. При удалении не удаляется `%LOCALAPPDATA%\GameLauncherPRO`, игры и неизвестные установщику файлы. Старую портативную папку и закрепление удаляют вручную после проверки установки.
2. Проверка перед запуском дополняет проверку EXE/процесса/места: наличие Steam и незавершённая операция модов. Проверка доступна отдельно в быстрых действиях и ПКМ. Это не проверка всех файлов игры или гарантированного FPS.
3. Первый запуск: три шага — поиск установленных игр, необязательное подключение Steam, навигация по функциям. Любой шаг можно пропустить. Поиск и подключение запускаются только по кнопке. Повторно открыть мастер можно в настройках.
4. Экспорт библиотеки, профилей, коллекций и закреплений рекомендаций; контрольная сумма, предпросмотр восстановления и страховочная копия. При ошибке записи возвращаются предыдущие файлы. Завершение восстановления полностью закрывает лаунчер; следующий запуск перечитывает настройки. Секреты, заметки, аргументы запуска, иконки и тексты обращений не экспортируются. Импортированные профили и автокопии не включаются автоматически; пути могут потребовать исправления на другом ПК.
5. Безопасный режим: `--safe-mode` или отдельный ярлык. Отключены сетевые загрузки, загрузка иконок/обложек, применение профилей, передача дополнительных аргументов и подготовка модов лаунчером; WARP/раздел модов недоступны. Уже установленные в файлах игры моды не удаляются. После некорректного завершения предлагается безопасный запуск. Обычный запуск возвращает стандартный режим без перезаписи настроек офлайна.
6. Отчёт об ошибке: версия, версия Windows, архитектура, число игр, последние служебные действия и описание пользователя. Маскируются пути, почта, SteamID и распространённые форматы секретов. Предпросмотр обязателен; отчёт сохраняется в TXT и прикладывается в Telegram пользователем. Автоматической отправки и дампов памяти нет. Маскирование не заменяет просмотр свободного текста человеком.
7. Место на диске: просмотр размеров установленных игр, обложек, описаний, кеша каталогов/загрузок и копий. Файлы игры доступны только для чтения. Очистка управляемых папок показывает список, требует подтверждения, не затрагивает новые или изменившиеся после предпросмотра файлы. Во время игр/загрузок/установок очистка недоступна. Удаление копий необратимо.
8. Совместимость Thunderstore: зависимости и конфликты версий проверяются до включения кнопки установки. Если автор не указал версию игры, интерфейс прямо пишет, что совместимость неизвестна. Дополнительное явное поле `playspace_game_versions` допускает точные версии EXE, но не заполняется догадками из описания. Файловые конфликты проверяются установщиком после загрузки до изменения файлов.
9. Шестерёнка карточки открывает быстрые действия: запуск, моды выбранной игры, сохранения, готовность, графика и папка. Те же действия доступны по ПКМ. Моды из быстрого действия открываются с выбранной игрой.
10. Данные рекомендаций: отдельные состояния загрузки, чтения кеша, отсутствия данных и кнопка повтора. Ошибка получения обложки больше не запоминается навсегда как пустой результат. У каталогов модов сохраняются отмена и обновление; центр загрузок показывает очередь/ошибки отдельно от установки.

## Где искать

«Моё пространство» → мастер настройки / перенос настроек / место на диске / отчёт / безопасный режим. Эти же пункты есть в «Настройки → Приложение». Быстрые действия — шестерёнка на карточке или ПКМ.

## Сборка и проверки

```powershell
dotnet run --project GameLauncherGUI.Tests -c Release -- --launcher-health --ui
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Build-Installer.ps1
```

Для сборки установщика нужен официальный Inno Setup 6.7+; путь можно указать `-Compiler`. Скрипт не публикует релиз и не устанавливает лаунчер на ПК разработчика.

Подписи SignPath пока нет. Установщик не отключает политики безопасности и не гарантирует устранения блокировки `.lnk` Smart App Control. Проверка поведения на отдельном клиентском Windows 11 с включённой защитой остаётся необходимой перед публичным выпуском.
